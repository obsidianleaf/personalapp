# Виртуальная книжная полка (PWA)

Приложение книжного клуба: участники делятся бумажными книгами — дарят, обмениваются, дают почитать.
Заменяет три гугл-формы (регистрация, добавление книги, действия с книгами) и таблицу-каталог.

## Что умеет

- **Регистрация** — заявка с именем из чата клуба. Админ подтверждает её, приложение создаёт пароль, админ пересылает его участнику.
- **Каталог** — поиск, фильтры по статусу, условиям, жанру и владельцу; миниатюры обложек; номер книги (№001).
- **Добавление книги** — те же поля, что были в гугл-форме; имя владельца подставляется само.
- **Бронирование, передача, возврат, отмена брони** — оформляет владелец книги из её карточки. Статус в каталоге меняется сразу, всё пишется в историю.
- **Мои книги** — кабинет: мои книги, что я сейчас читаю, что забронировано для меня, что получено навсегда.
- **Фото обложки** — необязательно, можно добавить сразу или позже.
- **Админ** — заявки, участники, выдача нового пароля, блокировка, назначение второго админа, добавление участника без заявки.

## Где хранятся данные и обложки

Всё лежит в одной базе PostgreSQL, обложки — тоже (отдельное файловое хранилище не нужно).
Фото сжимается на телефоне до отправки: обложка до 900 px (обычно 60–200 КБ) и миниатюра 320 px (около 10 КБ).
Сервер не принимает файлы больше 300 КБ. Бесплатных 0,5 ГБ хватит на пару тысяч книг с фотографиями.

## Запуск на своём компьютере

```bash
cd bookshelf
npm install
ADMIN_NAME="Ваше имя" ADMIN_PASSWORD="ваш-пароль" node server.js
```

Без `DATABASE_URL` данные хранятся во встроенной базе в папке `bookshelf/data`.

## Установка для клуба (бесплатно)

1. **База.** Зарегистрируйтесь на [neon.tech](https://neon.tech), создайте проект и скопируйте строку подключения (`postgresql://…`).
2. **Сервер.** На [render.com](https://render.com): New → Blueprint → выберите этот репозиторий. Для сервиса `knizhnaya-polka` задайте:
   - `DATABASE_URL` — строка из шага 1;
   - `ADMIN_NAME` — ваше имя в чате клуба;
   - `ADMIN_PASSWORD` — ваш первый пароль (потом смените в «Профиле»).
3. **Телефон.** Откройте адрес сервиса (`https://….onrender.com`) в браузере → меню → «Добавить на главный экран» / «Установить приложение».
4. Войдите как админ, в «Профиле» добавьте участников или дождитесь их заявок. Ссылку на приложение отправьте в чат клуба.

На бесплатном тарифе Render сервер засыпает после 15 минут без посещений, первое открытие после паузы занимает до минуты.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | PostgreSQL. Если не задана — встроенная база в `DATA_DIR` |
| `DATA_DIR` | Папка встроенной базы (по умолчанию `bookshelf/data`) |
| `ADMIN_NAME`, `ADMIN_PASSWORD` | Первый админ; создаётся, только пока в базе нет ни одного админа |
| `PORT` | Порт (по умолчанию 3000) |

## Правила статусов

| Действие | Кто может | Что происходит |
|---|---|---|
| Забронировать | владелец | «Свободна» → «Бронь» |
| Отменить бронь | владелец или тот, для кого бронь | «Бронь» → «Свободна» |
| Дал(а) почитать | владелец | книга «на руках» у читателя, со сроком возврата |
| Вернули | владелец или читатель | книга снова «Свободна» |
| Отдал(а) навсегда / Обменял(а) | владелец | книга переходит новому владельцу и уходит с полки; он может вернуть её на полку. При обмене встречная книга из каталога переходит обратно автоматически |

Админ может выполнять любые действия за владельца.
