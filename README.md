# Мой дневник (PWA)

Личное приложение: Работа, Здоровье, Финансы, Хобби. Ввод голосом, текстом и фото квитанций/скриншотов оплаты. ИИ (Claude) раскладывает запись по разделу, вытаскивает сумму, дату, категорию; вы подтверждаете одним касанием.

## Запуск
```bash
ANTHROPIC_API_KEY=sk-ant-... APP_TOKEN=любой-секрет node server.js
```
Без `ANTHROPIC_API_KEY` приложение работает с упрощённым разбором текста (фото без ИИ уходят в очередь).
Для установки на телефон приложение должно открываться по HTTPS (разверните на Render/Fly/VPS или откройте через `cloudflared tunnel`).
Затем в браузере: «Добавить на главный экран». В Настройках введите `APP_TOKEN`.

## Что есть
- Голос (Web Speech API, ru-RU), текст, фото (камера/галерея/«Поделиться» на Android).
- Подтверждение распознанного, предупреждение о дублях, офлайн-очередь для фото.
- Финансы: месяц, расходы/доходы, бюджет и остаток, категории, экспорт CSV.
- Разделы с лентой, поиском и фильтрами; переименование разделов.
- PIN-блокировка, данные только на устройстве (IndexedDB), экспорт/импорт резервной копии.
